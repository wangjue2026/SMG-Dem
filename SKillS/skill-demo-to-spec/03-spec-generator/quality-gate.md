# 交付质量自检清单 (Quality Gate 10 铁律)

在输出《设计说明书》与数据资产包之前，转换技能**必须强制执行逐项核验**。只有当 10 项自检全部通过（10/10 全绿）时，方可交付给用户。

---

## 10 项自检核验标准

| 序号 | 检查项目 | 验收标准 | 违规表现（严禁） |
| :---: | :--- | :--- | :--- |
| **1** | **离线与内网兼容性** | 100% 杜绝一切外网 CDN（如 jsdelivr, unpkg, google fonts） | 说明书中残留外网 JS/CSS 链接导致内网加载超时 |
| **2** | **组件语义化严谨度** | 严格映射为 IDUX 标准组件，杜绝原生 HTML 代替组件 | 使用原生 `<select>`、手写 `<table>`、原生模态遮罩等 |
| **3** | **页面模板映射与排版保真度** | 明确命中 14 种标准页面模板之一；找不到匹配的标准模板时，必须包含完整的【定制复合页面结构描述】；100% 保真还原原复合排版（如卡片大盘+下表明细） | 擅自压平复合排版为单一表格，或未识别页面模板、盲目套用错误模板且无定制结构描述 |
| **4** | **线框图文本纯净度** | 线框图 UI 内部只有干净的真实业务文本 | 在按钮或表头里带出 `(EP-xx)` 或规则标记 |
| **5** | **表单左右结构铁律** | 所有表单控件必须遵循“左文本标题、右输入组件”的水平结构 | 出现上下堆叠（Vertical）的表单布局 |
| **6** | **组件选型与可视化资产识别保真度** | 基础组件命中 IDUX 首选；四大类可视化资产（趋势图、拓扑图、可视化图表、业务图表）绝对禁止套用基础 UI 组件，必须分类明确并 100% 保真提取物料（SFC / ECharts）与 Token 字典 | 虚构组件名，或强行将横向拓扑硬套成垂直 `<IxTimeline>`、把三色底带散点时间线乱套成单色折线图、遗漏趋势图基线配置 |
| **7** | **交互行为细则与异常状态完备度** | 第二章必须包含《交互行为与操作细则大表》记录因果联动；第三章必须明确定义 Loading、Empty、Error、防重复提交 | 只给静态线框图而缺失交互因果说明，产出无交互死页面；或缺失异常状态机 |
| **8** | **数据契约可运行度** | `types.ts` 语法合法，Mock 数据无循环依赖，可直接 import | 类型包含 `any` 敷衍了事，或 Mock 数据与界面字段脱节 |
| **9** | **资产隔离无污染** | 所有产出物存放在独立转换输出目录，绝不修改织雨主干 | 往 `skill-designer-prism/` 写入逆向文件 |
| **10** | **复杂方案 1+N 分册铁律** | 页面数 ≥2 或累计 HTML > 150KB 时，必须拆为 1 个全局总控 + N 个模块分册 | 把多页面方案硬塞成单一超长巨石说明书，导致内容截断或研发无法拆包 |
