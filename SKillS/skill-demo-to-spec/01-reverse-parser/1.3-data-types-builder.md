# 1.3 数据模型反推与 TypeScript 契约生成规范 (Data Types Builder)

## 一、解析目标
将 HTML 中静态写死的假数据（如 `ai-dem-data.js`、`window.DEM_DATA`、内联表格每行每列的值）进行提纯与结构归一化，反推输出符合工业级标准的 TypeScript 接口与独立 Mock 数据包。

---

## 二、类型反推规约

1. **实体与字段命名标准化**：
   - 将原 Demo 中的非标中文键名或缩写（如 `app_nm`, `val1`）转为语义明确的驼峰命名字段（如 `appName`, `metricValue`）。
   - 提取业务枚举（如应用状态 `'normal' | 'warning' | 'critical'`）。

2. **接口输出结构规范 (TypeScript)**：
   ```ts
   // types.ts 示例
   export type HealthStatus = 'normal' | 'warning' | 'critical';

   export interface AppMetricItem {
     id: string;
     name: string;
     category: 'Web/SaaS' | 'TCP' | 'Custom';
     status: HealthStatus;
     rttMs: number;          // 往返时延 (ms)
     packetLossRate: number; // 丢包率 (%)
     activeUsers: number;    // 当前活跃用户数
     timestamp: string;      // 监控记录时戳
   }

   export interface AppQueryFilter {
     keyword?: string;
     category?: string;
     status?: HealthStatus;
     dateRange?: [string, string];
   }
   ```

3. **Mock 数据包生成原则**：
   - 保持数据的逼真度与多样性（至少包含正常、告警、严重异常 3 类不同形态的数据行）；
   - 数据必须能够直接被前端工程无副作用引用（ES Module 导出）；
   - 支持与 Vue 3 `ref()` 或 Pinia Store 直接绑定。
