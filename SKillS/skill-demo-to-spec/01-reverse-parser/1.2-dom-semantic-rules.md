# 1.2 非标 DOM 识别为业务语义组件规则 (DOM Semantic Rules)

## 一、解析目标
将 HTML 中由原生标签、Tailwind 原子类以及手写 CSS 拼接出的“伪组件”，准确识别并提升为对应的**标准业务语义**与 **IDUX 标准组件**，剔除垃圾样式。

---

## 二、典型 DOM 模式识别对照表

| 原 HTML / Tailwind 特征 | 识别提取的业务语义 | 映射标准组件 (IDUX) | 关键配置要求与尺寸 Token |
| :--- | :--- | :--- | :--- |
| `<select class="dem-select ...">` | 条件选择器 / 筛选项 | `<IxSelect>` | 默认使用 `size="sm"`（高度 32px）、圆角 2px、边框 `#E1E5EB` |
| `<input type="text" class="... border ...">` | 搜索/关键字输入 | `<IxInput>` | 默认使用 `size="sm"` 或 `size="md"`，带清除按钮与搜索图标 |
| `<div class="dem-table-container"><table>...` | 核心数据列表视图 | `<IxTable>` / `<IxProTable>` | 提取所有 `<th>` 转换为 `columns` 配置，提取行内特殊样式为自定义插槽渲染 |
| `<span class="bg-green-100 text-green-700 ...">` | 业务状态标记 / 标签 | `<IxTag>` | 映射语义状态：`status="success"` / `"warning"` / `"error"`，严禁手写十六进制背景 |
| `fixed inset-y-0 right-0 ... dem-drawer` | 详情排障 / 配置侧拉面板 | `<IxDrawer>` | 宽度统一为 `440px` 或 `640px`，右侧滑出，受控 `v-model:visible` |
| `fixed inset-0 flex items-center justify-center` | 确认 / 表单浮层 | `<IxModal>` / `IxProFormModal` | 标题栏、正文区、底部主次双按钮操作条 |
| `<button class="bg-blue-600 text-white ...">` | 主操作按钮 | `<IxButton mode="primary">` | `size="sm"`（表格工具栏）或 `size="md"`（弹窗底部） |
| `<div class="grid grid-cols-4 gap-4">` 内含大数字 | 宏观指标统计卡片 | `<IxCard>` + `IxText` | 采用浅底色、去框线化，数字采用等宽字体（`tabular-nums`） |
| 垂直时间序列事件流 / 审计记录 | 简单时序记录 | `<IxTimeline>` | 仅用于垂直时间流；严禁将横向端到端链路拓扑硬套为此组件 |
| 横向端到端诊断拓扑链（终端➔POP➔连接器➔网关➔应用） | 核心业务网络诊断链 | **业务特化组件 (`DemTopologyChain.vue`)** | **IDUX 无对应组件**。按样式 100% 保真提取为 Vue 3 SFC：44px 圆形节点、2px 状态彩色连线、SVG 箭头、打钩/打叉及 RTT/丢包气泡 Badge，支持节点与链路点击事件 |
| 访问体验时间线（三色底带+离散采样散点折线） | 业务离散时序态势图 | **业务特化组件 (`DemScatterTimeline.vue`)** | **严禁强套普通折线图**。100% 保真还原三段浅色背景（绿/橙/红）、灰色虚线折线、动态高亮光环散点、垂直蓝色虚线标尺与悬浮 Tooltip，支持散点点击联动 |
| 标准动态时序指标走势（RTT/丢包连续折线） | 连续时序图表 | 平台标准图表容器 + ECharts | 剥离 `setOption({...})` 纯配置，适配 `ResizeObserver` |

## 三、清洗与去噪原则（严格禁止项）

1. **彻底丢弃 Tailwind Reset 与杂音类**：
   - 过滤 `w-screen`、`h-screen`、`overflow-hidden`、`font-sans` 等页面外壳强行占位的类名。
2. **剔除绝对定位与手写阴影**：
   - 原 Demo 中使用 `absolute top-12 left-0 shadow-2xl` 拼凑的下拉菜单，全部替换为 IDUX 组件内置的浮层机制。
3. **消除硬编码色彩**：
   - 原 Demo 中的 `#1C6EFF` 映射为 `--ix-color-primary`（主题色 Token）。
   - 原 Demo 中的 `#D9363E` / `bg-red-50` 映射为 `status="error"` 语义色。

---

## 四、空间排版保真铁律（严禁擅自压平或降维结构）

1. **复合结构严禁降维**：
   - 原 HTML 中若存在「顶部资产/指标卡片网格 (`grid grid-cols-3`) + 下方明细表格」的上下结构，说明书线框图与组件映射必须**100% 忠实还原该复合布局**，绝对禁止为了省事将其压平成单一的普通大表格！
2. **抽屉下钻动线精准提取**：
   - 卡片内若带有“查看清单 >”或“新建”按钮并绑定了 `drawerOpen` / 抽屉模板，必须将其精准映射为独立的 `<IxDrawer>` 子组件规约，严禁把抽屉内的列表强行塞回主页面。
3. **真实业务文案与数字 1:1 提取**：
   - 提取的 Mock 数据与说明书中的展示，必须如实反映原 HTML 的实际数量（如 42 个私有应用、86 个 SaaS 应用）与具体应用名称，禁止脱离源码虚构无关数据。

## 五、页面级模板映射判定 (Page Template Mapping)

在组件映射之前，必须先定性页面整体架构模板：

1. **比对 14 种 Common Design 标准页面模板**（详见 `02-design-assets/page-templates/01-page-types.md`）：
   - `page-table-basic` (基础表格页)
   - `page-table-tree` (左树表格页)
   - `page-table-overview` (概览表格页)
   - `page-dashboard` (Dashboard 大盘)
   - `page-detail-drilldown` (下钻详情页)
   - `page-drawer-detail` (抽屉详情页)
   - `page-form-config` (配置表单页) 等。
2. **找不到匹配时的单独定制描述机制 (Fallback)**：
   - **严禁生拉硬拽**：当页面不符合任何单一标准模板时，**必须声明为定制复合页面模板**（如 `custom-monitor-config-composite`）；
   - **必须在说明书第二章中单独给出定制页面骨架描述**：
     - ① 顶部 Header（48px）及操作按钮区；
     - ② 核心内容分区分割比例（如卡片大盘区高度 280px + 表格明细区 `flex-1` 自适应）；
     - ③ 视口滚动边界（是外层整体滚动还是表格区域内滚动）；
     - ④ 侧滑抽屉或模态弹窗与主页面的传参协议与联动范围。

## 六、四大类可视化资产识别与处理铁律 (Visual Asset Rules)

> [!CAUTION]
> **绝对认知：业务可视化资产无法映射到标准 UI 基础组件库**！  
> 绝对禁止将可视化图表强套成无关的基础 UI 组件。

必须精准识别并归入以下四大资产类型：

| 资产大类 | 典型示例 | 处理方案 | 核心 Token 与参数要求 |
| :--- | :--- | :--- | :--- |
| **📈 趋势图 (Trend Charts)** | 延迟/丢包时序走势图、双 Y 轴折线图、多指标堆叠面积图 | 提取为纯净 ECharts 配置函数 (`charts.config.ts`) | X 轴采样间隔、双 Y 轴单位、阈值 MarkLine（如 100ms 标红线）、曲线平滑度、渐变透明度 |
| **🌐 拓扑图 (Topology Graphs)** | 端到端 5 节点诊断拓扑链、调用链拓扑、服务依赖网格 | 提取为独立 Vue 3 SFC (`DemTopologyChain.vue`) | 节点尺寸 44×44px、状态色（健康绿 `#12A679`/告警橙 `#FA721B`/故障红 `#F52727`）、2px 彩色连线、SVG 箭头、点击 Emits |
| **📊 可视化图表 (Visualizations)** | 三色底带离散散点时序图、热力分布图、多维雷达图、漏斗图 | 提取为独立 Vue 3 SFC (`DemScatterTimeline.vue`) | 三色底带 HEX 与 5~6% 透明度、散点白描边 1.5px、选中蓝色脉冲光环、垂直标尺线 |
| **⏱️ 业务图表/仪表盘 (Gauges)** | 网络健康度半圆仪表盘、SLO 达标进度条带、卡片内嵌 Sparkline | 提取为轻量级 SVG/Canvas 业务卡片组件 | 起始与结束角度、刻度分段、彩色进度带厚度、指标数值字体 |
