第二章：核心页面与抽屉线框示意及组件选型

2.1 页面空间结构描述 (严格依据 DOM 树还原)

  • 顶部 Header (固定 48px)：左侧 14px 加粗标题“体验监控”，右侧组合时间筛选器（左侧快捷按钮高 32px 宽 84px，右侧日期范围展示框带日历图标）、刷新按钮（32×32px）、智能排障按钮（圆角胶囊渐变边框）。
  • 顶部综合概览大卡片 (展开高约 170px，支持折叠)：
    • 采用 grid-template-columns: 30% 40% 30% 分割线布局；
    • 左侧 30% 体验预警事件分布：大字 24px 待处置数字 16，中间 76×76px 环形图（中心问题总数 23），右侧四色图例（高优 4、中优 12、低优 1、已修复 4）；
    • 中间 40% 访问体验质量：分支（24个）、用户（3568个）、应用（171个）三行，每行展示“正常 X | 一般 Y | 差 Z”文本及多色堆叠进度条（绿/橙/红），支持点击直接筛选联动；
    • 右侧 30% VIP对象体验：右上角 `用户 / 应用` 双态按钮，副标题显示“监测用户 18 人，体验异常 5 人”与 `1/2` 翻页器，下方三行 30px 高度的 VIP 用户条目（何总、李达、吴刚）。
  • 下半区 3-Tab 数据工作区 (吸底自适应)：
    • 顶层 40px 高度 Tab 导航条：文字为纯文本 站点分支、访问用户、应用（无 emoji、无数字后缀），激活项底部展示 2px 蓝色指示条；
    • 筛选栏：左侧 3 个 188px 等宽多选下拉框（带已选 Tag、+N 折叠胶囊、悬停一键清除 X），右侧为 w-64 搜索输入框（无多余的导出或重置按钮）；
    • 表格明细：10 列表头，表头高 32px，访问体验列展示纯状态胶囊（差、一般、正常，无任何臆造分数），受损应用展示“首个应用 + 等 X 个”，操作列展示“详情”链接。

第三章：页面体验与异常保护规则

3.1 状态机完备性大表

运行状态 触发场景 / 前置事件 推荐 UI 组件与表现形式 用户可用交互出口 状态流转去向
加载中 (Loading) 初次进入页面、切换时间筛选、点击刷新 概览区使用 <IxSkeleton> 骨架屏；表格使用 <IxSpin> 遮罩。 禁用刷新按钮，保持 Tab 可点击。 请求成功 ➔ 正常展示态；请求超时 ➔ 异常态。
空数据 (Empty) 关键词无匹配结果、当前时间段无访问流量 展示 <IxEmpty description="没有匹配的分支机构体验数据">。 提供一键“清空筛选条件”按钮，快速恢复全貌。 点击清空 ➔ 恢复全量列表态。
请求异常 (Error) 后端监控网关超时、跨域报错或 500 异常 保留上一次成功渲染的数据，顶部滑出轻量级 <IxAlert type="error">。 提供“重试连接”按钮，允许手动触发补发。 点击重试 ➔ 进入 Loading 态。
防重锁定 (Lock) 用户高频连续快速点击“刷新”或“智能排障” 按钮展示内置 Spin 并置灰不可点击（锁定 1.5 秒）。 鼠标展示 not-allowed 禁用手势。 接口返回或延时到达后自动解锁。
