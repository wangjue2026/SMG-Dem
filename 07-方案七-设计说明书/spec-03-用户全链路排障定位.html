一、模块架构与业务流转拓扑

1.1 模块定位与职责

用户全链路排障定位中心 是针对单用户/单应用深度时延劣化排障的核心中枢。 通过整合用户画像概况、多应用离散时序散点图、端到端 5 节点连通性拓扑链 与 逐跳 (Hop-by-Hop) 根因定位矩阵， 实现从宏观告警下钻到单次访问微观切片（如 15:20 POP-连接器骨干专线丢包）的秒级定界定因。

1.2 定制复合页面空间架构说明 (严格对齐 DEM-用户详情.html 左右分栏)

复合排版定型 (custom-user-diagnostic-composite)： 依据 DEM-用户详情.html 原型 DOM 结构，页面整体由“顶部两层固定栏 + 下方左右两栏排障核心容器”构成：
1. 页面 Sub Header (固定 48px)：左侧面包屑导航 (体验监控 / 访问体验监控 / 2024106（刘洋）- 排障定位)，右侧统一时间范围选择器与刷新按钮；
2. 用户画像概况卡片 (88px，支持 x-collapse 收起)：12 列栅格，左 4 列为用户头像与组织/POP/终端信息，中 3 列为访问体验状态 Badge，右 5 列为监控应用统计 (18个监控/8个受损/2个一般/8个正常) 与折叠收起按钮；
3. 左右两栏排障核心容器 (自适应撑满剩余高度)：
  ● 左侧 240px 应用访问列表 (可折叠收起)：固定宽 240px，顶部含标题、体验状态筛选下拉框 (全部应用 / 体验差 / 体验一般 / 体验正常)、向左收起按钮 <<，下接搜索框 (placeholder="搜索名称/地址") 与纵向滚动应用列表。各应用展示三态圆点、名称与域名。收起后变为 32px 占位竖条带展开按钮 >>；
  ● 右侧自适应纵向滚动排障看板 (flex-1)：随左侧选中应用动态下钻，由上至下依次为：
    a. 访问体验趋势走势图 (90px)：三色底带 (优/良/差) 散点时序图，点击时序采样点联动下方诊断，15:20 故障时刻垂直标尺贯穿；
    b. 端到端 5 节点诊断拓扑链 (110px)：终端 ➔ 局域网/接入网络 ➔ POP网关节点 ➔ 骨干传输网 (红线高亮故障) ➔ 服务端应用；
    c. 故障根因收敛结论卡片：AI 定界举证报告，明确骨干专线丢包劣化根因，提供处置建议与【复制报告】；
    d. 逐跳 (Hop-by-Hop) 真实网络追踪明细表：7 列表头 Hop 明细，红字高亮时延与丢包跳点。

三、页面体验与异常保护规则

3.1 状态机完备性与防御矩阵

状态类型 表现形态与 UI 占位 防御机制与交互阻断 恢复路径与出口
加载中 (Loading) 拓扑节点与散点图进入骨架屏闪烁；Hop 表格居中 <IxSpin> 禁用应用切换胶囊与散点点击，避免切片时序错乱 异步切片数据就绪后平滑展开拓扑链
空数据 (Empty) 散点图全灰底，提示“该时段内无真实访问采样” 拓扑链隐藏链路度量 Badge，节点保持置灰 引导用户切换更广时间范围或选择其他监控应用
请求异常 (Error) Hop 追踪表局部呈现“链路探测数据超时”，标红警告 保留上层拓扑链已有概貌，不破坏页面整体排版 提供【重试探测链路】按钮
