一、模块架构与业务流转拓扑

1.1 模块定位与职责

全网体验预警中心 是全网数字体验劣化的中枢调度感知与处置中台。承载两大业务闭环： 一是告警事件感知与批量处置（按时间自适应时均/日均趋势走势、三大受损对象卡片过滤、8列告警明细表与批量改态模态框）； 二是预警策略闭环管理（支持针对分支、应用、用户三类对象的多阈值条件规则配置与通知触达抽屉）。

三、页面体验与异常保护规则

3.1 状态机完备性与防御矩阵

状态类型 表现形态与 UI 占位 防御机制与交互阻断 恢复路径与出口
加载中 (Loading) 卡片数字骨架屏微弱呼吸闪烁；表格居中渲染 <IxSpin> 禁用筛选框与批量修改按钮，防止并发重入请求 异步数据载入完毕自动渲染真实 DOM
空数据 (Empty) 展示 <IxEmpty>，提示“暂无预警事件” 隐藏批量操作按钮，保留时间筛选栏与配置入口 提供【调整时间范围】或【重置筛选】快捷文字链接
请求异常 (Error) 局部加载失败横幅展示，网络错误码回显 阻断破坏性操作，保留用户已输入的策略表单内容 提供【重新加载】重试按钮
防重提交锁 (Lock) 抽屉【确定保存】按钮进入 Loading 态 点击即刻进入防抖锁，禁用双击与快捷键重复触发 保存成功关闭抽屉并触发列表 Refresh，失败解锁提示报错
