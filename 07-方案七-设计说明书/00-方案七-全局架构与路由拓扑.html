三、跨页面传参协议与上下文契约

为确保系统在 Vue 3 单页应用 (SPA) 环境下平滑流转，跨模块跳转必须严格遵循统一的路由 Query 参数协议：

参数名 (Key) 类型 示例值 来源页面 ➔ 目标页面 业务语义与受控动作
userId string usr_001 / 45232 spec-01 / spec-02 ➔ spec-03 定位目标用户，自动装载该用户的 5 节点诊断拓扑与访问时序散点图。
appName string OA系统 / Salesforce spec-01 / spec-03 ➔ spec-04 筛选特定应用详情，自动绘制时序延迟走势与受影响用户列表。
timeRange [string, string] ['2026-06-04 00:00', ...] 全局同步 (Pinia Store) 顶层全局时间范围筛选器，跨所有分册共享时间窗口上下文。
shortcut string '今天' | '近24小时' | '近7天' 全局同步 (Pinia Store) 时间快捷模式标识，驱动时序图按小时（hour）或按天（day）聚合粒度。
branchId string br_001 (西安研发中心) spec-01 ➔ spec-01 抽屉 / spec-03 分支过滤下钻，展示该分支下受影响的用户明细。
