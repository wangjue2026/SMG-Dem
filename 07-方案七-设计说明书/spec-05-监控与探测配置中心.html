一、模块架构与业务流转拓扑

1.1 模块定位与职责

监控与探测配置中心 是 DEM 系统的规则与观测底座中枢。 三大核心工作台： 一是真实流量观测 (Real Traffic)：对 ZTNA 私有应用、常用 SaaS 应用及自定义应用进行纳入/屏蔽管理与明细维护； 二是主动探测配置 (Synthetic Probing)：配置分布在全国 POP/分支的 7x24h 探针巡检任务； 三是体验质量标准 (SLO Thresholds)：设定优秀、良好、卡慢预警、故障严重四档量化分级阈值。

三、页面体验与异常保护规则

3.1 状态机完备性与防御矩阵

状态类型 表现形态与 UI 占位 防御机制与交互阻断 恢复路径与出口
加载中 (Loading) 三张资产大卡片数值呈现骨架加载；自定义表格渲染 <IxSpin> 禁用【添加应用】与抽屉呼出操作 加载完成展示真实应用纳管总数
空数据 (Empty) 自定义应用明细表展示内置占位：“暂无自定义应用，上方 128 个核心业务已全量监控” 提供居中的【+ 添加应用】醒目引导按钮 支持随时录入私有扩展资产
防重锁 (Lock) 抽屉保存或删除确认时，按钮进入 Loading 锁定态 拦截快速连续点击，避免重复创建或重复删除 请求结束解除锁定并更新表格
