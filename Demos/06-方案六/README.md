# 06-方案六

本目录用于存放和维护**方案六**的 Demo 演示页面与相关文件（基于方案五副本独立演进）。

## 目录与文件规范
1. **标识与路径**：
   - **方案六** 路径：`Demos/06-方案六/`
2. **文件结构**：
   - `DEM-首页.html`：首页与全貌监控/指标下钻
   - `DEM-用户详情.html`：用户排障定位与画像详情
   - `DEM-应用详情.html`：应用详情与关联分析
   - `DEM-体验预警.html`：体验预警页面
   - `DEM-监控配置.html`：监控配置页面
   - `_shell/`：方案六独立的双底座框架（`shell.js` / `shell.css`）
