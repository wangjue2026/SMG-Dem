# 08-方案八

本目录用于存放和维护**方案八（迭代一拆解版）**的 Demo 演示页面与相关文件。
源副本来自 `Demos/07-方案七/` 定稿全量版本，在此副本上单独裁剪迭代一范围，**方案七原文保持不变**。

## 目录与文件规范
1. **标识与路径**：
   - **方案八** 路径：`Demos/08-方案八/`
2. **文件结构**：
   - `DEM-首页.html`：首页与全貌监控/指标下钻（已同步自 06-方案六 最新首页，含 AI 巡检条、巡检报告抽屉、体验预警摘要等）
   - `DEM-用户详情.html`：用户排障定位与画像详情
   - `DEM-应用详情.html`：应用详情与关联分析（独立重构演进版）
   - `DEM-体验预警.html`：体验预警页面
   - `DEM-监控配置.html`：监控配置页面
   - `_shell/`：方案八独立的双底座框架（`shell.js` / `shell.css`）
