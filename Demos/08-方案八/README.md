# 08-方案八

本目录用于存放和维护**方案八（迭代一拆解版）**的 Demo 演示页面与相关文件。
源副本来自 `Demos/07-方案七/` 定稿全量版本，在此副本上单独裁剪迭代一范围，**方案七原文保持不变**。

## 目录与文件规范
1. **标识与路径**：
   - **方案八** 路径：`Demos/08-方案八/`
2. **文件结构**：
   - `DEM-首页.html`：首页与全貌监控/指标下钻（已同步自 06-方案六 最新首页，含 AI 巡检条、巡检报告抽屉、体验预警摘要等）
   - `DEM-用户详情.html`：用户排障定位与画像详情
   - `DEM-应用详情.html`：应用详情与关联分析（独立重构演进版）
   - `DEM-体验预警.html`：体验预警页面
   - `DEM-监控配置.html`：监控配置页面
   - `_shell/`：方案八独立的双底座框架（`shell.js` / `shell.css`）

## 二次修订记录（首页字段与口径）

1. 「体验异常对象集中位置」三档改为 **同归属地 / 同接入POP / 同链路**；i 提示同步更新，同链路指**在当前时间范围内，探测分支 / 用户访问不同业务时识别到的体验差的链路**；条目标签宽度 52 → 68px。条目数值展示为「N 人 | N 分支」（文字色 #3D3D3D），**人数与分支数可分别点击**：点人数只筛用户清单并切到用户 tab，点分支数只筛分支清单并切到分支 tab；整行点击仍为两个清单同筛；再次点击同一数字取消。筛选后条件会**回填到对应工具栏筛选器**（同归属地 → IP 归属地、同接入POP → 接入POP、同链路 → 体验差的链路），取消筛选时同步移除回填项；**反向同样联动**——在工具栏删除 Tag / 全部清除时，集中位置的筛选状态、条目高亮与副标题一并复位（以工具栏条件是否仍存在为激活判定）。工具栏下拉选项改为「固定项 + 数据出现的值 + 当前已选」动态合并。
2. 分支 / 用户表「链路」列改为「体验差的链路」，只取体验为差的链路（首条 + 其余 `+N`），无差链路显示 `-`；工具栏链路筛选的选项集合同步为差链路。
3. 用户表「最近使用终端 / IP 归属地 / 最近接入 POP」支持多值：默认展示最高频项，其余以 `+N` 收起，悬浮按使用频次降序列出全部取值并标注前三项为「高频」。示例多值行：`14810（郝星伍）`、`63728（王浩）`。
4. 分支 / 用户表「访问应用数」字段改为「探测应用数」（数值口径不变，仅改名）。
5. 应用表「受损/活跃用户」「受损/活跃分支」改为「体验差的用户」「体验差的分支」，去掉活跃数，只保留体验差的数量；两列表头与数值均右对齐。
6. 列序调整：用户表为 访问体验 → 体验差的链路 → 体验差的应用 → 探测应用数；分支表为 …主要接入POP → 体验差的链路 → 体验差的应用 → 探测应用数。
7. 三张表内「体验差的应用 / 体验差的用户 / 体验差的分支」的数字均可悬浮查看具体对象清单，超过 8 个以「等 N 个」收尾；应用侧对象清单由 `degradedUserNames` / `degradedBranchNames` 提供，数量与表格数字严格一致。
8. 表格内的悬浮信息统一改为**自定义即时浮层**（`hoverTip` + `x-teleport` 到 body 的 fixed 浮层），不再使用浏览器原生 `title`（原生提示有 1s 以上延迟且不可控）；覆盖体验差应用/用户/分支、体验差的链路、最近使用终端、IP 归属地、最近接入 POP、所属组织架构。浮层深色 `#1F2733`、11px、逐行展示，靠近视口右侧/底部时自动翻转位置，不阻塞鼠标事件。

`DEM-应用详情.html` 的「分支探测质量」「用户探测质量」两个 tab 表格同步：链路列改为「体验差的链路」，仅展示对象访问过程中体验为差的链路（对象体验为差时取其接入链路，体验正常/一般显示 `-`）；工具栏链路筛选的选项集合与匹配逻辑同步为差链路，占位文案改为「全部体验差的链路」。
