# SMG-DEM 交互与设计规范

## 下拉筛选组件一键清除交互规范 (Select Clear Rule)
1. **一键清除交互统一**：全项目所有单选或多选下拉筛选框（Select/Multi-Select），其一键清除交互必须保持视觉与操作的高度统一。
2. **原位替换原则**：
   - 默认态/未悬停态：仅在右侧展示标准下拉箭头（Arrow），无论是否有已选值。
   - 悬停态（Hover）且有选中值：下拉箭头原位平滑替换为圆形一键清除按钮（`X`），点击立即清空选中项并恢复“全部”状态。
   - 未选中任何值时：悬停不显示清除按钮，保持显示下拉箭头。
3. **禁止冗余与并排图标**：
   - 禁止在多选标签 Tag 内放置细碎独立的删除叉号。
   - 禁止在输入框右侧常驻并排呈现双图标（如“清除按钮 + 下拉箭头”并列），以维持界面干净极简。

## 拓扑节点 Hover 浮层规范
1. 拓扑图中的聚合节点（如用户终端、分支机构、POP等），鼠标悬停时应呈现精美、层级清晰的分布统计浮层（Popover）。
2. 浮层内应提供归一化的统计维度（如 IP 归属地分布、分支地理位置分布），呈现人数/数量、百分比进度条与异常体验标识。
3. 浮层中的明细项应支持点击直接联动过滤页面下方的主体明细表格。
